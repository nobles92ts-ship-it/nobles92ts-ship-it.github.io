**AI가 대신 웹을 조작해 주는 브라우저입니다. 제 컴퓨터에는 설치가 안 됩니다. 한 줄로 끝날 기각이었는데, 제가 적은 「계획 없음」이 틀렸다는 게 저쪽 변경 기록에서 드러났습니다.**

> **[도판]** 기능 목록이 아니라 권한 설계가 이 물건의 알맹이다. 로그인된 채로 남을 대신 조작하려면 거기부터 답해야 한다.
>
> 이 물건은 브라우저 확장이 아니라 브라우저 자체다. 별도 연동 없이 이미 로그인된 사이트를 사람처럼 조작한다. 권한은 네 영역에 걸쳐 세 값 규칙으로 잡고, 에이전트 기본값 위에 태스크별 설정이 덮인다. 모델은 구독 재사용과 API 키와 역방향 연결 세 갈래로 붙는다.

## 이게 뭐 하는 물건인가

브라우저 확장이 아니라 **브라우저 자체를 새로 만든 것**입니다. 문서가 못을 박습니다 — **「최소 브라우저 버전 같은 건 없다. 이게 브라우저니까.」**

AI가 제 대신 웹을 돌아다니며 조작합니다. 자료를 찾고, 양식을 채우고, 눌러야 할 걸 누릅니다.

만든 곳은 **5명짜리 팀**이고, 요금은 무료·월 20달러·월 200달러 세 단입니다.

## 이 물건에서 배울 건 기능이 아니라 「권한 설계」였습니다

AI가 제 대신 웹을 조작한다는 건 **로그인된 상태**로 움직인다는 뜻입니다. 그러면 바로 문제가 생깁니다 — **비밀번호를 AI에게 보여 줄 것인가.**

이 물건의 답이 좋았습니다.

| 결정 | 어떻게 |
|---|---|
| **비밀번호를 AI에게 안 보여 준다** | 저장된 값은 **AI에게 숨기고**, 주소와 조건을 확인한 뒤 **페이지에 직접 채워 넣음** |
| **권한을 세 단으로** | 읽기만 / **정해진 폴더 안에서만**(기본) / 전체 |
| **거부가 최우선** | 허용·질문·거부 세 값인데 거부가 이김. 그리고 **작업별 설정이 기본 설정 위에 덮임** |
| 기록을 기억으로 | 「이 일엔 이 사이트」를 스스로 앎 |

첫 줄이 핵심입니다. **AI에게 비밀번호를 안 보여 주면서 로그인 상태를 쓰게 하는** 것 — 이게 사실상 유일한 방법입니다.

## 그런데 「1위」 주장이 자기 채점이었습니다

홈페이지에 <strong>「성능 평가 세 종에서 1위, 큰 회사들을 앞섰다」</strong>를 내걸고 99.0%라는 숫자를 붙여 뒀습니다.

따라가 봤습니다. 그 숫자는 **자기네 창고에 자기네 채점 방식으로 올린 자가 보고**였습니다.

- 제3자가 재현한 기록 **없음**
- 독립 순위표에 **등재 자체가 없음**

「1위」라는 말은 **누가 매긴 순위인지**가 있어야 뜻이 생깁니다. 자기가 매긴 자기 순위는 순위가 아닙니다.

## 제 환경과 대 봤더니

| 항목 | 요구 | 제 환경 | |
|---|---|---|---|
| 운영체제 | 특정 OS 전용 | **윈도우 두 대** | **설치 불가** |
| 계정 | 있어야 함 | 있음 | 충족 |
| **핵심 기능** — 로그인된 상태로 웹 조작 | 이게 파는 것 | **이미 되고 있음** | **중복** |
| 업무 도구 접근 | 화면을 사람처럼 클릭 | **직통으로 연결됨** | **제 쪽이 나음** |

세 번째와 네 번째 줄이 중요합니다.

이 물건이 파는 핵심 기능을 **저는 이미 다른 방법으로 쓰고 있었습니다.** 그리고 업무 도구는 **화면을 클릭하는 것보다 직통 연결이 더 낫습니다** — 화면은 바뀌면 깨지는데 직통은 안 그렇습니다.

## 그리고 제가 적은 「계획 없음」이 틀렸습니다

여기가 이 편에서 값을 치른 자리입니다.

처음에 저는 이렇게 적었습니다 — **「윈도우 지원 계획 없음.」** 근거는 **다운로드 페이지에 윈도우 판이 없다**는 것이었습니다.

그 뒤에 **변경 기록**을 열어 봤습니다. **윈도우 판 이야기가 세 번 나왔습니다.**

즉 다운로드 페이지에는 없는데 **변경 기록에는 있었습니다.**

→ 배운 것:

> **「없다」를 다운로드 페이지에서 볼 것인가, 변경 기록에서 볼 것인가.**

다운로드 페이지는 **지금 받을 수 있는 것**을 보여 줍니다. 변경 기록은 **지금 만들고 있는 것**을 보여 줍니다. **「계획」을 물었으면 뒤쪽을 봐야** 했습니다.

## 종합 판정 — 기각인데, 시계가 앞당겨졌습니다

결론은 그대로 **기각**입니다. 지금 설치가 안 되고, 핵심 기능은 이미 있고, 업무 도구는 제 쪽이 낫습니다.

바뀐 건 **언제 다시 볼까**입니다. 「계획 없음」이었으면 영영 안 봐도 됐는데, **만들고 있는 중**이면 이야기가 다릅니다.

그래서 **다시 열 조건 다섯 개**를 적어 두고 닫았습니다.

## 여기부터는 자세한 기록입니다

**설치가 안 됩니다.** macOS 15 이상 전용이고 제 PC는 둘 다 Windows입니다. 여기서 끝나면 한 줄짜리 기각인데, **처음에 적은 「Windows 계획 없음」이 틀렸습니다** — 다운로드 페이지에는 없지만 **체인지로그에 Windows 빌드가 세 번 나옵니다.** 그리고 저 사람들이 내건 *"에이전트 벤치마크 1위"* 는 **자기 저장소에 자기 채점으로 올린 수치**였습니다. 종합 판정은 그대로 기각인데, **재개 조건의 시계가 크게 앞당겨졌습니다.**

## 무엇을 하는 물건인가

**AI 에이전트 브라우저입니다.** 확장 프로그램이 아니라 브라우저 자체를 새로 만들었고, 문서가 못을 박습니다 — *"별도의 최소 브라우저 버전이 없다. Aside가 브라우저니까."*

파는 가치는 **별도 연동 없이 이미 로그인된 사이트를 대신 조작하는 것**입니다. API 붙일 필요 없이, 사람이 하던 클릭을 그대로 합니다.

| 항목 | 값 |
|---|---|
| 정체 | 크로미움 기반 설치형 데스크톱 브라우저 |
| 출신 · 규모 | 액셀러레이터 2025년 가을 기수 · **5명** · 출시 2026-06-23 |
| 플랫폼 | **macOS 15.0+ 전용.** 공개 Windows·Linux 빌드 없음, 대기자 명단도 없음 |
| 요금 | 무료 $0(월 500 크레딧) / Pro $20 / Max $200 |
| Claude 경로 | 구독 재사용 · API 키 · **역방향 연결** 셋 다 열림 |

⚠ **"웹에서 쓰면 되지 않나"는 안 됩니다.** 공식 사이트는 소개·다운로드 페이지일 뿐 제품이 아닙니다. 로그인 콘솔도 웹앱 진입점도 없고 다운로드 버튼만 있습니다.

## 깨본 결과

**1위 주장이 자가 채점이었습니다.** 홈에 *"에이전트 벤치마크 3종 1위 — OpenAI·Anthropic·Browser Use를 앞섰다"* 를 내걸고 99.0%라는 수치를 붙였는데, 그 숫자는 **자기 저장소에 자기 채점 셋업으로 올린 자가보고**입니다. 제3자 재현이 없습니다. 독립 리더보드에는 아예 등재가 없습니다.

⚠ **그리고 대조가 비대칭입니다.** 이 벤치마크는 *모델 + 도구 + 정책*을 묶은 시스템 단위 비교인데, 비교 대상으로 세운 Claude는 **도구 없는 맨몸 모델**입니다. *"Anthropic을 이겼다"* 는 문장은 그렇게 만들어졌습니다.

**보안 문서라고 준 주소가 보안 백서가 아니었습니다.** 열어보니 권한 UI 설명서입니다. 암호화 방식·저장 위치·학습 사용 여부·감사 로그가 **전부 빠져 있습니다.** 홈에 적힌 *"외부 API 키를 쓰지 않는 한 아무것도 모델 제공자에게 공유되지 않는다"* 는 문서로 뒷받침되지 않는 마케팅 문장 상태입니다.

**그리고 제 판단 하나가 틀렸습니다.** 다운로드 페이지에 Windows가 없어서 *"계획 없음"* 이라고 적었는데, **체인지로그를 전량 읽으니 Windows가 세 번 나옵니다.**

> **[도판]** 기각에도 종류가 있다. 「영영 안 될 것」과 「조건이 실제로 도래할 수 있는 것」은 감시 주기가 다르다.
>
> 체인지로그에 윈도우 빌드가 세 번 등장한 뒤 두 달째 침묵하고 있다. 5월 12일 확장 포함, 6월 1일 프로필 가져오기, 6월 23일 메뉴 개선까지 나온 뒤 6월 말부터 8월 중순까지 릴리스 아홉 건에 윈도우라는 단어가 한 번도 없다. 그래서 출시 임박이 아니라 후순위로 밀렸다고 읽는다.

## 판정

| 무엇 | 판정 |
|---|---|
| 도구 도입 | **기각 — 플랫폼.** 설치가 안 됩니다 |
| 자격증명 비노출 주입 | **점검 후 결정.** 제 테스트 계정 처리 방식을 **열어보지도 않고** "개선점"이라 단정하지 않습니다 |
| 허용·질문·거부 + 태스크 오버레이 | **보류.** 세 값 규칙은 이미 있습니다. 새로운 건 **태스크 단위 덮어쓰기 하나**뿐입니다 |
| 기록을 기억으로 | **이미 보유.** 제 메모 서랍이 같은 일을 합니다 |
| 벤치마크 1위 인용 | ⚠ **금지.** 자가 채점입니다 |

**실행 순서는 「아무것도 안 한다」입니다.** 지금 이득이 0이라 비용을 쓸 자리가 없습니다. 권한 기법은 **게이트를 손댈 일이 생겼을 때 그 자리에서 같이** 봅니다 — 단독 착수 금지.

**재개 조건 다섯을 남깁니다.** ① Windows 브라우저 공개 배포 ② **Windows 명령줄 도구** — 이게 진짜 조건입니다 ③ 제가 macOS 장비를 갖게 될 때 ④ 제3자 감사 리더보드 등재 ⑤ 보안 백서 공개. 추적 지점까지 적어 뒀습니다 — 설치 스크립트의 분기가 늘어나는지, 다운로드 페이지에 버튼이 생기는지.

**이 편에서 값을 치른 교훈은 「없다」를 어디서 확인했느냐입니다.** 다운로드 페이지만 보면 없고, 체인지로그를 전량 읽으면 만들고 있었습니다. **판정은 안 바뀌었지만 재개 조건의 성격이 「언젠가」에서 「실제로 도래할 수 있는 것」으로 바뀝니다.**

그리고 ⚠ **수확 폭을 부풀리지 않는 게 이 편의 절반입니다.** 권한 기법 2종이라 적었다가 대보니 절반은 이미 있는 것이었고, 남은 건 **하나**였습니다. 그래서 판정이 채택이 아니라 보류입니다.
