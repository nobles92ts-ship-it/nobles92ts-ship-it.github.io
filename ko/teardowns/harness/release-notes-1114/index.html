Codex 0.169.0 쪽은 터미널 화면에 관한 기능이 앞에 섭니다. 옆 대화 탭 여러 개, 지난 작업 검색, 끝난 활동을 접어 두는 보기, 터미널에서 모델 제공자를 추가하는 기능, 클라우드 대화를 터미널에서 다루는 기능입니다.

개발자용 파이썬 SDK 는 11월에 Anthropic 이 v2.52.8, OpenAI 가 v3.483.51 까지 나왔습니다. Anthropic 쪽 수정은 Bedrock·Vertex 같은 클라우드 경로에 빈 값이나 . .. 가 들어가는 것을 막는 줄이 많았고, OpenAI 쪽은 타입이 붙은 비동기 함수 도구와 에이전트 세션 옵션이 들어왔습니다. 이 둘은 릴리스 제목과 앞부분만 읽었습니다.

값을 치르고 배운 것

앞부분만 읽은 요약은 «새 기능 위주»로 기운다. 릴리스 노트는 새 기능을 맨 위에 두는 문서라, 앞 700자는 구조상 가장 새 것에 가깝습니다. 전문을 세어 보고서야 첫 요약이 수정 줄의 절반을 못 본 채 쓴 것임을 알았습니다.

항목 수는 활동량이 아니라 적는 습관이다. 294 대 259 를 보고 두 회사의 작업량을 말할 수는 없습니다. 한쪽은 평평한 목록이고 다른 쪽은 큐레이션 열두 줄에 커밋 목록입니다.

못 한 것

  • 줄을 하나씩 읽고 분류하지 않았다. 첫 단어 일치와 키워드 개수가 전부이고, sandbox 14회가 보안 수정 14건이라는 뜻은 아니다.
  • 릴리스 두 장과 한 장이 표본의 전부다. «Claude Code 는 수정이 절반»이라는 일반화는 못 한다.
  • Codex 의 커밋 243줄은 세기만 했고 내용은 분류하지 않았다.
  • 0.171.0 알파 릴리스는 본문이 제목뿐이라 볼 것이 없었다.
  • 모델 성능이나 실제 체감 속도는 이 글의 범위 밖이다. 변경 기록이 말해 주지 않는다.
  • 소스 diff 는 열지 않았다. 노트가 «고쳤다»고 적은 것을 코드로 확인한 것은 없다.

판정

도입할 것이 없는 편입니다. 두 도구는 이미 쓰고 있습니다. 이 편이 남기는 건 읽는 법 하나입니다. 릴리스 노트를 볼 때는 앞부분의 새 기능 말고 중간의 «Fixed» 줄 중 격리·권한·토큰이 들어간 것을 따로 훑습니다. 새 기능은 쓰다 보면 알게 되지만, 막힌 구멍은 알려 주지 않으면 모르기 때문입니다.
