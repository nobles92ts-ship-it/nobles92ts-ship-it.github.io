How to write here

There is no upload box on this site. People I invite send a draft by email or a shared folder, and it goes up after a check and a read-through.

In one line — there is no upload box here. Send the draft by email or a shared folder, and I will put it into the site’s shape and publish it.

A writer never has to sign in to anything. No login, no password.

⚠ The real steps and rules sit below “The detailed record starts here”. The part above is the plain version of them.

Why there is no upload box

This site is a stack of pages built ahead of time and handed out as they are. Nothing runs when a visitor opens one, so the site cannot take in a draft and store it by itself.

A login box would need a server to do that job. A server means more to look after, and more places for things to leak.

So the receiving happens outside the site — in a mailbox and a shared folder.

How to send it

Either way works. Use whichever is easier.

Way How
Email Send the draft to the submissions address, in the body or as an attachment. I give you the address when I invite you
Drive folder Put the file into the folder you were invited to. I share that link when I invite you

The submissions address is not printed on this page, for two reasons. It would draw spam, and it would make the site look like anyone can send something in.

What happens next

I receive the draft, fix its shape, make the English version and run the machine checks. The writer then sees a preview first. If nothing needs changing, it goes up.

The detailed record starts here

What to include

  • A title in one line and a summary in one line. The summary shows up in the list as written.
  • The body. Any format is fine — a document file, an email body, markdown.
  • Pictures, if any, as files alongside the text. Say in one line where each one goes.
  • The name to print as the author. A real name or a nickname, whatever you decide.

The steps until it is live

  1. Receive. The draft arrives by email or in the folder.
  2. Tidy. It is put into the site’s shape — Korean original, plain explanation at the top. No edit changes the meaning. Only where sentences run on or fall into one beat is the rhythm smoothed, and you see that part.
  3. English version. Made with machine assistance, and the English page says so. Korean is the original.
  4. Machine checks. The draft has to pass the same checks the site runs before every publish: dead links, sentences copied from other pages, internal company terms, text that runs in one flat beat. If one trips, it is fixed and run again.
  5. Preview. You look at it in the real page shape. Tell me what to change at this step.
  6. Publish. It goes up when I give the last read and approve it. Nothing goes up without that.

What is not published

  • Internal information about a company or a client — names, numbers, screenshots, even document titles.
  • Other people’s personal information. If a name, a contact or a photo shows, it is removed before publishing.
  • Other people’s writing, moved over. Quotes are accepted short and with the source.
  • Posts whose point is advertising.

If a call is borderline, I ask before it goes up.

To change or take down a post

Tell me through the same route you sent it. Changing and taking down follow the same steps. A removed post disappears from the site, and any address left in search fades out over time.
